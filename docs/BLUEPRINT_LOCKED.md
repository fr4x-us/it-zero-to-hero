
# IT ZERO → HERO — Locked Blueprint V1

Status: LOCKED
Changes require explicit owner approval.

## Platform
- Native Android APK
- Kotlin + Jetpack Compose + Material 3
- Offline-first
- Room/SQLite, MVVM, Repository
- Colorful Academy, bright/light theme

## Curriculum
- 16 weeks, nominal 128 hours
- Four learning phases:
  1. IT foundations
  2. Mathematics and computational thinking
  3. Python programming
  4. Database, web basics, Git, capstone
- Linear module unlocking
- Academic theory, diagrams, labs, exercises,
  quizzes, projects, exams, and summaries
- Online YouTube videos are optional

## Assessment
- Theory: 30%
- Laboratory: 40%
- Mini-project: 20%
- Concept explanation: 10%
- Weighted final score must be at least 80
- Every component must be at least 75
- Unlimited remedial attempts
- Retain best component scores and all attempt histories
- No XP penalty and no XP farming
- Timed theory exams with persistent deadlines
- Flexible lab and project sessions
- Objective offline grading, no AI grading

## Laboratory
- Offline Python editor and execution
- Logic and flowchart activities
- SQL exercises
- Objective test cases
- Runtime compatibility and isolation require validation

## Gamification
- XP, levels, achievements, mastery
- Academic grades remain separate from XP

## Study calendar
- Japan timezone: Asia/Tokyo
- Japanese national holidays and substitute holidays
- Japanese calendar presentation
- Company working days are distinct from national holidays
- Flexible study scheduling
- Quiet hours: 22:00–07:00 JST

## Reliability and security
- Autosave and crash recovery
- Local snapshots
- Password-encrypted portable backup exports
- Safe restore preview, confirmation, validation,
  rollback, and attempt-history preservation

## UI
- Colorful Academy
- Five main tabs:
  Home, Learn, Lab, Calendar, Progress
- Profile and backup settings
- Accessible, readable, responsive Android UI
