# Pelajaran 1 — Apa Itu Komputer? Hardware, Software, dan Model IPOS

## Tujuan pelajaran

Setelah pelajaran ini kamu dapat:

1. Menjelaskan perbedaan **hardware** (perangkat keras) dan **software**
   (perangkat lunak) dengan contoh.
2. Menjelaskan empat tahap kerja komputer: **input**, **proses**,
   **output**, dan **penyimpanan** (*storage*).
3. Menentukan tahap mana yang terjadi pada sebuah kegiatan sehari-hari
   dengan komputer atau ponsel.

## Mengapa ini penting?

Semua topik IT yang akan kamu pelajari — sistem operasi, jaringan,
pemrograman, database — dibangun di atas satu gagasan sederhana: komputer
**menerima data, mengolahnya, menampilkan hasilnya, dan menyimpannya**.
Kalau gagasan ini jelas, kamu akan lebih mudah memahami mengapa sebuah
program lambat, mengapa file bisa hilang, atau komponen apa yang perlu
diganti.

## 1. Komputer adalah mesin pengolah data

**Data** adalah fakta mentah: angka, huruf, gambar, suara. Contoh: angka
`80`, `75`, `90` yang kamu ketik.

**Informasi** adalah data yang sudah diolah sehingga bermakna. Contoh:
"Rata-rata nilaimu 81,67".

Komputer adalah mesin yang **mengolah data menjadi informasi** dengan
mengikuti instruksi. Ponsel, laptop, komputer meja, bahkan mesin ATM adalah
komputer.

## 2. Hardware dan software

| | Hardware (perangkat keras) | Software (perangkat lunak) |
|---|---|---|
| Wujud | Benda fisik yang dapat disentuh | Kumpulan instruksi dan data; tidak dapat disentuh |
| Contoh | Keyboard, layar, prosesor, kabel | Aplikasi kalkulator, browser, sistem operasi |
| Bila rusak | Diperbaiki atau diganti fisiknya | Diperbaiki dengan memperbarui atau memasang ulang |

**Analogi:** hardware seperti **dapur dan peralatannya**; software seperti
**resep**. Dapur tanpa resep tidak menghasilkan masakan, dan resep tanpa
dapur hanya tulisan. Komputer butuh keduanya.

Hardware dan software selalu bekerja bersama. Saat kamu menekan huruf "A"
di keyboard (hardware), software menentukan apa yang terjadi: menulis huruf
di dokumen, atau memilih menu.

## 3. Model IPOS: input, proses, output, penyimpanan

```
[ INPUT ] ──► [ PROSES ] ──► [ OUTPUT ]
                  ▲│
                  │▼
           [ PENYIMPANAN ]
```

*Deskripsi diagram dg-w01-01:* empat tahap — data masuk (input), diolah
(proses), hasil ditampilkan (output); di bawah proses ada penyimpanan
dengan panah dua arah karena data dapat disimpan dan dibaca kembali.

| Tahap | Arti | Contoh perangkat |
|---|---|---|
| **Input** | Data masuk ke komputer | Keyboard, mouse, mikrofon, kamera, pemindai (*scanner*) |
| **Proses** | Data diolah mengikuti instruksi | Prosesor (CPU), prosesor grafis (GPU) |
| **Output** | Hasil disampaikan ke pengguna | Layar (monitor), speaker, printer |
| **Penyimpanan** | Data disimpan agar dapat dipakai lagi | SSD, harddisk (HDD), flashdisk, kartu memori |

Satu perangkat dapat menjalankan lebih dari satu tahap. **Layar sentuh**
menampilkan gambar (output) **dan** menerima sentuhan (input).

## 4. Contoh nyata: memotret dengan ponsel

1. Sensor kamera menangkap cahaya → **input**.
2. Prosesor ponsel mengolah cahaya menjadi foto dan memperbaiki kecerahan →
   **proses**.
3. Foto tampil di layar → **output**.
4. Foto disimpan di memori penyimpanan ponsel → **penyimpanan**.

## 5. Contoh terbimbing

**Soal:** Kamu mengetik tiga nilai ujian ke aplikasi lembar kerja
(*spreadsheet*), aplikasi menghitung rata-ratanya, hasilnya muncul di layar,
lalu kamu menyimpan berkas. Tentukan tahap IPOS tiap langkah.

**Cara berpikir:**

| Langkah | Pertanyaan bantu | Tahap |
|---|---|---|
| Mengetik nilai | Apakah data **masuk**? | Input |
| Menghitung rata-rata | Apakah data **diolah**? | Proses |
| Rata-rata muncul di layar | Apakah hasil **disampaikan** ke saya? | Output |
| Menyimpan berkas | Apakah data **disimpan untuk nanti**? | Penyimpanan |

## 6. Miskonsepsi umum

| Miskonsepsi | Yang benar |
|---|---|
| "Monitor adalah komputernya." | Monitor hanya perangkat output. Pengolahan terjadi di prosesor di dalam unit komputer atau laptop |
| "Software hanya aplikasi yang saya pasang." | Sistem operasi dan program di dalam chip perangkat juga software (Pelajaran 3) |
| "Data dan informasi itu sama." | Data adalah bahan mentah; informasi adalah hasil olahan yang bermakna |
| "Setiap perangkat hanya punya satu tahap." | Layar sentuh dan headset bermikrofon adalah input **dan** output |

## 7. Latihan terbimbing (`mod-w01.prac-01`, tidak dinilai)

1. Tulis apakah benda berikut hardware atau software: (a) printer,
   (b) aplikasi peta, (c) kabel USB, (d) aplikasi pemutar musik.
2. Tentukan tahap IPOS: (a) kamu memindai kode QR dengan kamera ponsel,
   (b) aplikasi membaca isi kode QR, (c) halaman pembayaran tampil di
   layar, (d) riwayat pembayaran disimpan.
3. Sebutkan satu perangkat yang menjalankan input **dan** output.

## 8. Cek pemahaman (tidak dinilai)

- Mengapa komputer butuh hardware **dan** software?
- Apa beda data `80, 75, 90` dengan informasi "rata-rata 81,67"?

## Pembahasan latihan (ditampilkan setelah pelajar mencoba)

1. (a) hardware, (b) software, (c) hardware, (d) software.
2. (a) input, (b) proses, (c) output, (d) penyimpanan.
3. Layar sentuh, atau headset dengan mikrofon.

## Ringkasan

- Komputer mengolah **data** menjadi **informasi** dengan mengikuti
  instruksi.
- **Hardware** = fisik; **software** = instruksi dan data. Keduanya wajib.
- Empat tahap kerja: **input → proses → output**, dengan **penyimpanan**
  untuk dipakai lagi.
